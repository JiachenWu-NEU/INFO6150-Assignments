# Imperial Japanese Battleships — Two-Page SCSS Demo

A two-page site (Overview + Ships) showcasing **CSS Grid**, **Flexbox**, and **advanced SASS/SCSS** techniques.  
Topic: **Imperial Japanese Navy battleships** (Yamato, Musashi, Nagato, Fusō).

## Pages
- `index.html` — Hero split (Grid #1), class gallery (Grid #2).
- `ships.html` — Filter/search (Flex #1), ship cards list (Flex #2), spec grid (Grid #3), responsive table (Grid #4).

## How to Run
Open index.html in a browser
(the scss part has alraeady been built up)
